    Runbook and plugin tools
    1. Identify the signed-in project with get_my_profile and list_creator_projects. Read its script, animation instructions and timing with get_creator_project_context. Use get_creator_workflow_status to resume an unfinished video.
    2. Read the saved scene IDs and revision with get_creator_video_draft. If you know the scene ID, go directly to get_creator_resolved_scene. Use list_creator_assets for existing private media IDs and get_creator_contract for the schema and renderer capabilities.
    3. Use apply_creator_scene_patch with the scene ID, latest expectedRevision and only the requested changes. Preserve measured timing, audio and unrelated layers. Objects and ID-keyed arrays merge. Use {"$replace": [...]} for an explicit array replacement. Patch changes.engineData.project to edit a shared map for just one scene.
    4. For visual styles, use list_creator_style_presets, get_creator_style_preset, apply_creator_style_preset or update_creator_style_preset as needed. Read the new revision after each save.
    5. Review the result with request_creator_scene_jpg and get_creator_scene_jpg_status. JPGs require a connected renderer. After a plugin edit, use Sync in Motion & export to load the saved revision in the browser. Use Motion & export for full playback or MP4 export.

    For a new video, use Script → Sync plan → Review maps → Motion & export. The Hindi Shorts defaults are Gemini Aoede, Social media · engaging, and 1.20× final speed. Reuse the final MP3 and its timestamps. For a browser edit, choose a target below, use View JSON, then Validate. Full Video Manifest replaces the timeline when saved.
