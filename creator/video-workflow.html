Make a video in Creator Studio

Use this workflow for every video you make with Codex, Gemini, or another assistant. Follow the same steps in the signed-in Studio project and pick up from whatever is already saved.

Start or resume a video

  1. Open the project and prepare the voiceover

    Open the project the user names, or create one for a new video. Under Script, generate the final MP3 from the supplied narration text. Select female Gemini Aoede, Social media · engaging, and 1.2× final speed when those are the requested settings. If the user supplies a recording, use that exact recording. Keep final audio in the project or private media library. Reuse a saved final recording whenever the script and audio are unchanged.

  2. Get exact timing

    Reuse timing already saved for the final recording. For new timing, use Local Whisper on the paired laptop or select OpenAI timing in a saved project. Keep measured times when correcting transcript words.

  3. Build the first draft

    Use Sync plan → Review maps → Motion & export. Match visuals to measured narration cues, review generated maps, and keep the result editable. Resume at the latest saved step when the draft already exists.

Edit one scene

  1. Open Motion & export and select the scene in Scenes or the timeline. Confirm its name and time range before editing.
  2. Use Selected scene for the name or scene type, Objects for screen overlays, and Edit scene for geographic map or battlefield content. You can add a new scene with Add scene when asked. Inspect its timing before saving.
  3. For a conversion or timeline edit, review the proposed change and choose Apply change or Discard. Check that narration, scene timing, and unrelated layers match the requested scope. Get explicit confirmation before replacing existing scenes.

Add, move, and resize artwork

  1. Open Media library → Upload & voiceover. Search by filename. For an existing image, choose Use in video. For a new attachment, use Choose files or drop them here to upload the exact file once. If the session cannot pass the attachment to the picker, identify the file and continue when it is available in the library.
  2. Select the target scene. Under Selected scene, choose Overlay artwork → Add image overlay. Add as scene in the media library creates a separate scene. For text, lines, and arrows, use Objects → Object type → Add object.
  3. Select the object in Objects or click it in the preview. Drag it to reposition it and use Resize selected object to resize. For precise placement, use X and Y. Use Scale for proportional resizing and Width and Height for the image’s fit box. Use Rotation, Opacity, and Forward or Backward as needed.
  4. In an overlay, X and Y locate the center of the object relative to the frame. The top-left is 0, 0 and the center is 0.5, 0.5. For example, x: 0.25, y: 0.72 places an object toward the lower left. Check the result at the actual playhead position.

Animate an object

  1. Set Start (s) and End (s) to control its visibility. These times are relative to the start of the selected scene.
  2. Seek to the first pose, select the object, and choose Key at playhead. Move the playhead forward and change position, scale, rotation, or opacity to add or update the next pose. Use Motion keys to inspect the values and easing.
  3. To shift a whole animated asset, change its base placement and the relevant position keys by the same amount. Check an early and a late frame to confirm its motion still lines up.

Edit a map or camera move

  • Open a map through Review maps or Selected scene → Edit scene. Use Map Editor for geographic routes, labels, and map-anchored artwork. Use Motion Studio Objects for screen-space captions, foreground images, and diagrams.
  • Set the framing at the start of the shot and choose Add camera keyframe. Seek later, pan, zoom, or change camera pitch, then add another keyframe. For a quiet shot, use a slow push, drift, or slight pitch change. Ease the camera while labels need to be read.
  • Use Draw route or Import animation for geographic wind arrows. Shape curves with several points, use an arrowhead and timed reveal, and check them at multiple times. Geographic coordinates are longitude, latitude. For map-anchored artwork, use its layer’s Scale and preview its placement through the camera move.
  • For portrait geography, turn on Style → Shorts safe-area guide during review and keep labels clear of the bottom and right edges. Use Save now to checkpoint the current map, or Save scene & continue to save and move to the next map.

Make precise or batch edits with JSON

  1. Open Draft JSON → View current draft JSON. Read the textarea directly or use Download JSON. Select the intended scene by ID and time range.
  2. In a copy of the complete manifest, change the requested fields. Keep stable scene IDs, ordering, timings, audio clips, asset references, and unrelated layers. Use only asset IDs present in the draft. Register an image through Use in video first if it’s only in the library.
  3. Paste or upload the complete JSON. Choose Review import → Apply reviewed import → Save. If review rejects the file, read the exact error and correct the field before applying. If Studio says a change is pending, use the visible Apply change or Discard review first.

Save, preview, and verify

Save and reopen the draft. Verify the changed scene and its neighbors, then check the audio and timing. Preview movement after it begins. JPG previews show each scene’s first frame. When export is requested, choose Export MP4 and check the downloaded video and narration. If the browser is in 2D fallback, verify saved camera keys and layers there and use a WebGL2 session for terrain, satellite imagery, and the final map render. Report any check that remains pending.

What to say in a new chat
