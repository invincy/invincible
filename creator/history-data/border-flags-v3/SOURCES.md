# Country flag overlays

Original SVG flags downloaded from Wikimedia Commons. Clipping to regional geometry is editorial map composition; the flag designs are not AI-generated. Map projections use Web Mercator. India texture uses the Indian claimed extent; foreign textures are clipped outside that extent. Shading and internal control lines separately represent administration.
