Creator Studio

Make a video in Creator Studio

Use this workflow for every video you make with Codex, Gemini, or another assistant. Follow the same steps in the signed-in Studio project and pick up from whatever is already saved.

  1. Open the project and prepare the voiceover

    Open the project the user names, or create one for a new video. Under Script, generate the final MP3 from the supplied narration text. The default is female Gemini Aoede, Social media · engaging, at 1.2× final speed. If the user supplies a recording, use that exact recording. Keep final audio in the project or private media library. Reuse a saved final recording whenever the script and audio are unchanged.

  2. Get exact timing

    Use Timing & plan to run local Whisper on the final recording, or reuse timing already saved for that recording. Timing needs the paired laptop. Use Copy timing for Codex when you need the timestamps for scene planning. Download timing only if you need a file handoff and copying is unavailable. Keep measured times when correcting transcript words.

  3. Add supplied artwork to the private library

    In Motion & export → Create & import → Media → Upload & voiceover, upload the exact attached PNG or other media once using Studio’s file picker. Reuse the existing library asset if that same file is already saved. Use its media reference in the scene. If the assistant can see the attachment but cannot pass the file to the picker, ask the user to upload that file in Studio, then continue. Use public or generated artwork only when the request calls for it. GitHub is unnecessary for attached files.

  4. Build and review editable scenes

    Use the narration cues and visual direction to build the first draft. Director is optional for proposing that draft. For an assistant handoff, use Motion & export → Create & import → Copy ChatGPT brief for the current manifest and media references. Paste the complete updated manifest into Review import, then use Apply reviewed import. JSON can be copied and pasted directly.

    Preview scenes individually and flag geography that needs checking. For a revision, open the latest saved version and change the requested scene or layer. Preserve scene IDs, other scenes, audio timing, and unrelated layers. Use the native controls for small changes. Get explicit confirmation before replacing existing scenes with a new draft.

  5. Save, export, and verify

    Use Save scene & return after editing map layers and Apply change after reviewing a timing edit. Preview the full timeline and use Save & export MP4 to save the applied Motion Studio draft before rendering. Check the exported animation after the effects are due to appear and verify that the narration plays through. JPG previews show each scene’s first frame. Return the project link and the MP4. If browser access or a required file is missing, identify the exact step that needs the user and continue from the project once it is available.
